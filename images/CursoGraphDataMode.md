Refatoração de dados duplicados
Nesta lição, você aprenderá como eliminar a duplicação de valores de propriedades criando nós.

Aqui está o nosso modelo de instância atual, onde cada nó de Filme possui uma propriedade de idiomas:

Modelo de instância com linguagens
Para o nosso caso de uso mais recente:

Caso de uso nº 11: Quais filmes estão disponíveis em um idioma específico?

Esta consulta encontra todos os filmes em italiano :

cifra

Cópia

Correr
MATCH (m:Movie)
WHERE 'Italian' IN m.languages
RETURN m.title
O que essa consulta faz é recuperar todos os nós de Filme e, em seguida, verificar se a propriedade de idiomas contém italiano . Existem dois problemas com o modelo de dados, especialmente se o grafo for escalável:

O nome do idioma aparece duplicado em vários nós de Filme .

Para realizar a consulta, todos os nós de Filme devem ser recuperados.

Uma solução aqui é modelar as propriedades como nós.

Refatorar propriedades como nós
Aqui estão os passos que usamos para refatorar:

Pegue os valores das propriedades de cada nó de Filme e crie um nó de Idioma .

Crie a relação IN_LANGUAGE entre o nó Movie e o nó Language .

Por fim, remova a propriedade de idiomas do nó do filme .

Este é o código para refatorar o grafo e transformar os valores das propriedades em nós:

cifra
MATCH (m:Movie)
UNWIND m.languages AS language

MERGE (l:Language {name:language})
MERGE (m)-[:IN_LANGUAGE]->(l)
SET m.languages = null
Este código percorre todos os nós de Filme e cria um nó de Idioma para cada idioma encontrado, estabelecendo em seguida a relação entre o nó de Filme e o nó de Idioma usando a relação IN_LANGUAGE .

Utiliza a UNWINDcláusula Cypher para separar cada elemento da lista de propriedades de idiomas em um valor de linha separado, que é processado posteriormente na consulta.

Eis como o modelo de instância se apresenta após a refatoração:

Modelo de instância com nó de linguagem
Haverá apenas um nó com o valor de idioma "inglês" e removeremos a propriedade de idiomas de todos os nós de Filme . Isso elimina muita duplicação no grafo.
