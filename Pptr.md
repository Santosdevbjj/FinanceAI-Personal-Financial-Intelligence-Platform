Integrar uma arquitetura distribuída de backend padrão FAANG (ADVANCED_ARCHITECTURE.md) e um motor de IA com Open Finance (AI_ENGINEERING_OPEN_FINANCE.md) dentro de uma ferramenta visual de *Vibe Coding* como o **Lovable.dev** exige uma estratégia cirúrgica.
Como o plano gratuito do Lovable oferece **5 interações diárias**, não podemos desperdiçar comandos. O segredo para um projeto nível FAANG é usar o Lovable para construir um **Front-End "UI-Driven" altamente interativo**, que simula com perfeição matemática e visual o comportamento assíncrono, a segurança e a inteligência que você documentou.
Abaixo está o passo a passo detalhado, do zero à sincronização com o GitHub, estruturado para economizar seus créditos e maximizar o impacto visual para a banca avaliadora da CAIXA e DIO.
### 🚀 PASSO 1: Preparação do Terreno (Zero Créditos)
Antes de colar o primeiro comando no Lovable, prepare as definições que a IA precisará ler:
 1. Acesse o Lovable.dev e faça login utilizando sua conta do **GitHub**.
 2. Clique em **"New Project"**.
 3. Deixe o seu repositório do GitHub aberto em outra aba (FinanceAI-Personal-Financial-Intelligence-Platform).

### ⚡ PASSO 2: Interação 1 — O Prompt de Ouro (A Fundação do App)
No chat inicial do novo projeto no Lovable, você colará um prompt estruturado robusto. Ele criará todo o layout básico, componentes visuais e estados globais de uma só vez.
**Copie e cole o seguinte texto no Lovable:**
```text
Crie uma SPA (Single Page Application) ultra-moderna de inteligência financeira chamada "FinanceAI". A interface deve seguir um padrão premium (estilo Stripe/Apple), utilizando tons de verde mineral (#1e3a1e), cinzas escuros neutros, branco puro e fontes geométricas limpas. É um aplicativo responsivo (mobile-first).

O app deve conter um layout com uma Sidebar de navegação e uma área central dividida em duas colunas principais:
1. Painel de Controle Analítico (Esquerda/Topo): Exibe cartões com o Saldo Consolidado, o indicador dinâmico de "Dinheiro Livre para Gastar Hoje" baseado na Regra 60-20-20 (60% Essencial, 20% Estilo de Vida, 20% Poupança) e uma barra de progresso elegante para a Reserva de Emergência.
2. Feed de Conversação do Agente Guardião (Direita/Centro): Uma interface de chat fluida onde o usuário envia mensagens de texto ou simula o envio de comandos de voz.

Requisito de Dualidade de Interface: Inclua um botão Switch no Header chamado "Modo de Visualização".
- Quando desativado ("Modo Leigo"), a interface oculta tabelas e exibe apenas gráficos minimalistas e insights em linguagem natural (ex: "Você ainda tem R$ 45,00 livres para hoje").
- Quando ativado ("Modo Técnico/FAANG"), a interface revela micro-widgets de infraestrutura com métricas simuladas em tempo real: "Latência do Pipeline de IA (ms)", "Score de Confiança NER (%)", "Status do Mascaramento LGPD (Ativo)" e "Sincronização Open Finance (Conectado)".

```
*Após o processamento, o Lovable gerará toda a interface de usuário (UI) funcional e os modos de visualização.* **[Consumo: 1/5 Interações]**

### 🧠 PASSO 3: Interação 2 — Injetando o Motor NER de Inteligência Artificial
Agora vamos dar vida ao chat para que ele simule exatamente o processamento de linguagem natural que você documentou no arquivo de Engenharia de IA.
**Cole este prompt no chat do Lovable:**
```text
Agora, vamos implementar a lógica simulada do Motor NER (Named Entity Recognition) no input do chat. Configure o estado do chat para que, quando o usuário digitar uma mensagem e clicar em enviar, o sistema exiba uma animação sutil de "IA processando payload..." por 800ms. 

Crie uma lógica em TypeScript que faça um parse básico do texto digitado:
1. Se o usuário digitar palavras como "mercado", "carrefour" ou "aluguel", o chat deve responder com um card estruturado confirmando que a IA extraiu a transação, categorizou como [Essencial - 60%] e atualizou o gráfico do Dashboard automaticamente.
2. Se o usuário digitar "cinema", "restaurante" ou "iFood", classifique como [Estilo de Vida - 20%].
3. Adicione um pequeno botão "Ver Payload JSON da IA" em cada resposta do chat. Quando clicado, ele deve abrir um modal contendo o JSON estruturado da transação (com os campos amount, merchant, category e confidence_score) provando o funcionamento técnico do pipeline.

```
*Esse passo garante o "Efeito Uau" para os avaliadores técnicos, mostrando que a interface se comunica com um back-end inteligente simulado.* **[Consumo: 2/5 Interações]**

### 🔀 PASSO 4: Interação 3 — Componente de Sincronização Open Finance e LGPD
Para fechar os requisitos do seu segundo documento, precisamos mostrar visualmente os fluxos de segurança e integração bancária.
**Cole este prompt no chat do Lovable:**
```text
Adicione uma aba ou seção flutuante chamada "Central de Governança & Open Finance". Dentro dela, implemente:
1. Um botão para "Conectar Banco via Open Finance (BACEN)". Quando o usuário clica, simule uma animação de consentimento mTLS segura e mude o status para "Sincronizado". Gere uma lista de 3 transações fictícias vindas do banco que aparecem na tabela técnica após a sincronização.
2. Um painel de monitoramento de Privacidade LGPD. Exiba visualmente um fluxo simulado demonstrando como os dados sensíveis (como Nome e CPF) passam por um filtro de anonimização e mascaramento antes de irem para os logs públicos. Use badges coloridas como [MASCARADO - AES-256] para indicar segurança.

```
*Com isso, todas as funcionalidades complexas descritas na arquitetura ganham uma representação visual impecável na tela.* **[Consumo: 3/5 Interações]**

### 🛠️ PASSO 5: Interação 4 e 5 — Polimento Estético e Ajustes de Bugs
Use as duas interações restantes para corrigir pequenos desalignhamentos, ajustar responsividade no celular ou refinar o contraste de cores (padrão WCAG de acessibilidade).
 * *Exemplo de prompt:* `"Refine o espaçamento dos cartões do dashboard no mobile para que não quebrem a linha de forma errada e adicione um efeito de hover suave (shadow-lg) em todos os botões clicáveis."* **[Consumo: 4/5 e 5/5 Interações]**

### 📈 PASSO 6: O Gran Finale — Sincronização Automática com o GitHub
O Lovable possui integração nativa com o GitHub. Você não precisará baixar o código para a sua máquina e fazer commits manuais se não quiser.
 1. No canto superior direito da tela de desenvolvimento do Lovable, clique no botão com o ícone do **GitHub**.
 2. Clique em **"Connect to GitHub"** e autorize o repositório.
 3. Selecione o seu repositório oficial: Santosdevbjj/FinanceAI-Personal-Financial-Intelligence-Platform.
 4. Escolha a branch principal (main) e clique em **"Publish/Push changes"**.
A IA do Lovable vai empacotar toda a aplicação em **React, TypeScript, Vite e Tailwind CSS** e fará o upload direto para o seu repositório de forma limpa e organizada.

### 🏆 Como defender esse projeto na Mentoria ao Vivo (Dica FAANG):
Quando os avaliadores da CAIXA abrirem o seu projeto, mude a chave para o **"Modo Técnico"**. Mostre a tabela de latência, o validador de confidencialidade da IA, a simulação do log LGPD e clique no botão de visualizar o payload JSON gerado pelo chat.
Isso provará que você não criou apenas uma interface bonita, mas planejou a arquitetura completa de engenharia de software de uma plataforma financeira real.
